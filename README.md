# DSP Capture Viewer 使用手册

## 安装与启动

1. 解压 `DSP-Capture-Viewer.zip` 到任意目录
2. 在 IDE 中启动 DSP 代理（如 `or_debug_proxy.exe -r 4333 --chip13x`）
3. 双击 `DSP-Capture-Viewer.exe`

> 无需安装 Java，解压即用。

## 基本操作

### 开始采集

1. 顶栏选择通道数（1–4）和刷新率（30/60 FPS）
2. 点击 **▶ Start**
3. 波形开始实时滚动，状态栏显示采集速率

### 停止采集

点击 **■ Stop**，波形保留在界面上可供回放分析。

### 清除数据

点击 **✖ Clear**，弹出确认后清空所有采集数据。

## 波形交互

| 操作 | 效果 |
|------|------|
| **鼠标悬停** | 显示十字准线和各通道当前值 |
| **滚轮上/下** | 以光标位置为中心缩放波形 |
| **点击波形区** | 激活键盘控制 |

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| **Space** | 切换 实时 / 冻结 |
| **← →** | 左右平移波形 |
| **Home** | 跳到最早数据 |
| **End** | 跳到最新数据 |

---

## 回放控制

### 状态切换

| 按钮 | 状态 | 说明 |
|------|------|------|
| **● LIVE**（绿色） | 实时 | 波形自动跟随最新数据 |
| **○ LIVE**（灰色） | 冻结 | 可拖动滑块浏览历史 |

点击按钮切换，或按 **Space** 键。

### 浏览历史

- **拖动滑块**：自由滚动到任意时间点（自动冻结）
- **▶ Play**：以恒定速度自动回放
- **⏸ Pause**：暂停回放
- **− / +**：水平缩放波形

## 统计表

表格显示当前可视窗口内的统计值：

| 列 | 含义 |
|----|------|
| **Show** | 点击 ✔ 切换通道显示/隐藏 |
| **Ch** | 通道编号（彩色圆点标识） |
| **Current** | 最新采样值 |
| **Min** | 窗口内最小值 |
| **Max** | 窗口内最大值 |
| **Avg** | 窗口内平均值 |
| **Peak-to-Peak** | 峰峰值（Max − Min） |

## 导出数据

点击 **⇩ Export CSV**，选择保存目录。

导出格式：
```
time_us, Ch0, Ch1, Ch2, Ch3
0.0, 0.000000, 0.000000, 0.000000, 1.000000
200.0, 0.024541, 0.010101, -0.991597, 1.000000
...
```

每 200μs 一行，通道值时间对齐。

## 状态指示

| 指示灯 | 含义 |
|--------|------|
| ● 绿色 | 采集中，数据正常 |
| ● 橙色 | DSP 停摆（超过 2 秒无数据），波形自动冻结 |
| ● 红色 | 连接错误 |
| ● 灰色 | 空闲 |

## 常见问题

**Q: 点击 Start 提示连接失败？**

确认 IDE 中已启动 DSP 代理，端口 4333 未被占用。

**Q: 波形不动，指示灯变橙色？**

DSP 可能已停止运行，检查 IDE 中 DSP 状态是否为 Running。

**Q: 缩放后波形只占一部分？**

正常现象——放大到样本数少于屏幕像素时，波形会拉伸至全宽。缩小即可恢复。

**Q: 想在其他电脑上用？**

直接把解压后的整个文件夹复制过去即可，不需要装任何东西。
